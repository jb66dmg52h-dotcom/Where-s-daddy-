# Mica Face Support Packet Notes

This directory preserves the local Mica Face rebuild evidence collected on
2026-07-10.

The firmware source snapshot from that packet is represented by this Git
repository itself, so the duplicate `source-archives/where-s-daddy-clean-source.tar.gz`
file was not committed.

The Waveshare `ESP32-C6-LCD-1.47-Demo.zip` vendor archive was also left out of
Git because it is a large third-party binary. The accompanying vendor readme
files are kept here for reference.

Credential values in copied configuration files are intentionally redacted.
